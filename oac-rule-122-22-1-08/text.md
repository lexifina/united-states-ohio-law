# Rule 122:22-1-08: Severability.
If any clause, provision or application of any of the rules 122:22-1-01 to 122:22-1-08 of the Administrative Code is determined to be invalid or unenforceable, such determination shall not affect the remainder of such rule, other application of the rule, or application of other rules of this chapter, which shall be applied as if the invalid or unenforceable portion, application or references to the invalid or unenforceable portion did not exist.
