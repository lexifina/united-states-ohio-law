# Rule 109:1-5-14: Quarterly report requirements for veteran and fraternal organizations conducting electronic instant bingo.
In addition to the other records required to be kept by Chapter 2915.
of the Revised Code and any rules promulgated thereunder, all licensed e-bingo
organizations shall file a quarterly report with the attorney general upon a
form prescribed by the attorney general. The report will require electronic
instant bingo records to be kept and reported separately.
