# Rule 111:3-10-05: Subcontracting.
If a print vendor subcontracts any part of a board
order for mailing materials to be used in an election, the following
requirements apply:
(A) The print vendor shall notify the
board and secretary of state in writing of the subcontract, include the name,
and contact information for the subcontractor, and state which parts of the
order the subcontractor will complete.
(B) The subcontractor shall be governed
under these rules in the same manner as the print vendor.
