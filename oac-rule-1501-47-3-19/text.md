# Rule 1501:47-3-19: Lakes permitting ten horsepower.
No person shall operate or permit the operation of
a powercraft propelled by a motor or combination of motors with a horsepower
rating in excess of ten horsepower through the waters of the division of parks
and watercraft in the following state park areas:
Cowan lake state park
Guilford lake state park
Jesse Owens state park
Lake Logan state park
Wolf Run state park
Strouds Run state park
