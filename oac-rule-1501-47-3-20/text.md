# Rule 1501:47-3-20: Lakes permitting more than ten horsepower.
Powercraft propelled by a motor with a horsepower
rating in excess of ten horsepower may be operated upon the waters of the
division of parks and watercraft in the following park areas.
Buckeye lake state park
Deer creek state park
Delaware state park
Dillon state park
Grand Lake St. Marys state park
Indian lake state park
Lake Loramie state park
Lake White state park
Mosquito state park
Portage lakes state park
Rocky Fork state park
Salt Fork state park
West Branch state park
Alum creek state park
Buck creek state park
Paint creek state park
Caesar creek state park
East fork state park
Lake Milton state park
