# Section 3115.609: Procedure to register child-support order of another state for modification.
A party or support enforcement agency seeking to modify, or to modify and enforce, a child-support order issued in another state shall register that order in this state in the same manner provided in sections 3115.601 to 3115.608 of the Revised Code if the order has not been registered. A petition for modification may be filed at the same time as a request for registration, or later. The pleading must specify the grounds for modification.
Effective: January 1, 2016; Latest legislation: House Bill 64 - 131st General Assembly.
