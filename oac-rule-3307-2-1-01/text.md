# Rule 3307:2-1-01: Definitions.
Except where another definition is specified, for
the purposes of sections 3307.80 to 3307.89 of the Revised Code and Chapters
3307:2-1 to 3307:2-6 of the Administrative Code all definitions can be found in
the plan document, which is the document or documents adopted by the retirement
board to establish the defined contribution program or any of its constituent
plans.
