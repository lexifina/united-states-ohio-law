# Rule 1301:6-3-13: Withdrawal of application or notice filing.
(A) If an application to register
securities pursuant to section 1707.09, 1707.091, or 1707.39 of the Revised
Code has been on file with the division for more than one year without becoming
registered, the division may withdraw the application without prejudice and
refund the qualification fee.
(B) If a notice filing submitted to
the division pursuant to section 1707.092 of the Revised Code has been on file
with the division for more than one year without becoming effective, the
division may withdraw the notice filing and refund the filing fee.
