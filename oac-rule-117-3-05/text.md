# Rule 117-3-05: Request for proposals, quotes, invitations to bid.
Where the auditor of state has determined that an audit will be performed by an independent certified public accountant, the auditor of state will prepare a request for proposals, quotes, or invitations to bid. This document will clearly set forth:
(A) Clear and accurate specifications of the requirements of the audit;
(B) Minimum requirements which independent certified public accountants seeking the audit engagement must fulfill; and
(C) The period or periods to be covered by the audit.
